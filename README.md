# ChorePal – Smart Chore Management Android App

## 📌 Project Overview

ChorePal is an Android application designed to help families manage household chores and encourage children to build responsibility through a structured chore and reward system.

Parents can create and assign chores to children, monitor their progress, review completed chores, and approve completed tasks. Children can view their assigned chores, mark them as completed, submit photo proof, and track their earned rewards.

The project is being developed as part of a Capstone course and focuses on applying software engineering practices to the development, testing, and deployment of a real-world mobile application.

---

## 🎯 Objectives

* Simplify household chore management
* Help children build responsibility through assigned tasks
* Provide a structured reward system
* Provide separate experiences for parents and children
* Build a simple and user-friendly Android application
* Apply software development and testing practices throughout the project

---

## 🚀 Key Features

### 👨‍👩‍👧 Parent Features

* Create household chores
* Assign chores to children
* View assigned and created chores
* Monitor children's chore progress
* Review completed chores
* Approve completed chores
* Track children's rewards
* Manage children within the household

### 👦 Child Features

* View assigned chores
* View chore details
* Mark chores as completed
* Upload a photo as proof of completion
* Submit completed chores for parent review
* Track earned rewards

### 🔐 Authentication & User Roles

* User registration
* User login
* Parent and child accounts
* Role-based access to application features

### 🏆 Reward System

* Chores can have rewards associated with them
* Parents can approve completed chores
* Approved chores contribute to the child's reward total
* Children can view their earned rewards

### 🤖 AI Features

ChorePal includes an AI-based Household Statistics and Insights feature that provides information about chore completion and generates insights based on household chore data.

AI-based image verification for chore completion is planned as a future enhancement.

## 🏗️ System Architecture

ChorePal is currently implemented as an Android application using Firebase for data storage and application functionality.

### Current Architecture

* **Frontend:** Android application built with Kotlin
* **Development Environment:** Android Studio
* **Database:** Firebase Firestore
* **Authentication:** Application-based user authentication and role management
* **Version Control:** Git and GitHub

The application uses Firebase Firestore to store and retrieve information related to users, households, chores, and rewards.

---

## 📱 Platform

ChorePal is currently developed for **Android** using Kotlin and Android Studio.

The application is tested using Android devices/emulators with an Internet connection for Firebase functionality.

Future versions may expand support to additional platforms.
